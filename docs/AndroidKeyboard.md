# Android 하드웨어 키보드 계약

Android `NativeActivity`의 NDK 키 이벤트를 iiGUI 위젯 입력에 전달한다. 위젯의
포커스·선택·편집 상태는 iiGUI 또는 이를 사용하는 LVUI가 소유한다. 운영체제의
`KeyCharacterMap`으로 키보드 장치와 수정 키에 맞는 Unicode 문자를 얻으며 키 코드에
영문 자판을 고정하지 않는다. 방향·Tab·Enter·Space·삭제·Home·End·Page·Insert와
문자 키의 누름·해제를 전달하고 자동 반복은 운영체제 이벤트 순서를 유지한다.

조합 악센트는 같은 장치와 포커스에서 다음 문자와 결합하며, 결합되지 않는 경우
악센트와 문자를 순서대로 전달한다. 포커스 상실·포인터 누름·장치 변경은 미완성
악센트를 폐기한다. Ctrl 또는 Meta 단축키는 일반 문자로 중복 입력하지 않으며,
오른쪽 Alt를 사용하는 AltGr 문자 입력은 유지한다. 텍스트 입력 대상에서 선택·복사·
잘라내기·붙여넣기는 기존 위젯 입력 및 클립보드 서비스를 사용한다. 비밀번호는
복사하지 않으며 클립보드 쓰기에 실패한 잘라내기는 원문을 지우지 않는다.

취소된 키 해제는 위젯에 키 취소로 전달하여 버튼을 실행하지 않고 누름 상태를
해제한다. 이 취소는 실제 포커스 상실이 아니므로 텍스트 포커스를 유지한다.
알 수 없는 키와 지원하지 않는 장치의 이벤트는 Android가 계속 처리할 수 있도록
반환한다. 키 맵을 읽지 못한 경우 확인되지 않은 문자를 추측하지 않는다.
Android Back은 운영체제 활동 종료 요청으로 처리하며, 취소된 Back 해제는 창을
닫지 않고 소비한다.

소프트 키보드의 `InputConnection`·조합 문자열·화면 표시와 접근성은 이 하드웨어
키보드 계약만으로 제공되지 않는다. JNI 키 맵의 실제 기기 동작은 모형 테스트나
NDK 크로스 빌드만으로 입증할 수 없다.
