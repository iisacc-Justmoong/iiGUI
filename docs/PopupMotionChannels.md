# 팝업 크기와 불투명도 전환 계약

기존 단일 진행률의 팝업 동작은 유지한다. `PopoverTransition::opacity`에
`PopoverOpacityTransition`을 지정한 팝업은 크기와 불투명도를 독립된 시간과 이징으로
보간한다. 두 트랙은 같은 `MotionPreferences`, 소유 스레드와
프레임 시계를 사용하며 게임의 시간 배율·일시 정지에는 영향을 받지 않는다.

팝업 옵션의 바이너리 배치가 바뀌므로 팝업 생성과 옵션 갱신 접점에는 새 ABI 태그를
사용한다. 이전 헤더로 컴파일한 객체와 새 라이브러리, 또는 새 헤더와 이전
라이브러리의 조합은 링크에서 거절되어야 한다. 호출 소스는 기본 태그 인자로 기존
호출 형태를 사용할 수 있다.

열림은 각각의 현재 값에서 목표 크기·불투명도 1로 전환한다. 닫힘은 즉시 입력을
차단하고 `closed`를 알린다. `hold_scale_on_exit`을 선택하면 닫는 순간의 크기를 유지한 채
불투명도만 0으로 전환하며, 픽셀은 마지막 필요한 트랙이 끝날 때까지 유지한다.
닫히는 중 다시 열면 표시 중인 값에서 이어진다. 완전히 닫힌 다음 다시 열 때는
축소된 크기와 불투명도 0에서 시작한다. 알림·수명·접근성 및 팝업 개수 한도는
기존 팝업 계약을 따른다.

시간은 기존 팝업과 같은 0~24시간 범위여야 한다. 잘못된 값이나 사용할 수 없는
프레임 공급자는 기존 상태를 변경하지 않고 오류를 반환한다. 모션 감소·비활성화는
두 트랙을 즉시 목표 상태로 완료하며, 속도 변경은 같은 시작점에서 두 시간에 함께
적용한다. 부모 숨김·호스트 퇴역에서는 두 트랙과 프레임 구독을 정리한다.
단일 트랙과 독립 트랙 사이의 전환은 애니메이션이 진행 중인 동안 `busy`로 거부해
각기 다른 표시값을 잃지 않는다. 트랙이 정지된 뒤에는 전환할 수 있다.

검사는 실제 창이나 GPU를 열지 않는 위젯 트리와 주입한 Core 프레임 시계에서
각 트랙의 중간값·최종값, 닫기·재열기, 모션 설정 변경, 잘못된 설정, 기존 단일
트랙 호환성과 퇴역을 확인한다. 이는 운영체제별 애니메이션·렌더링 확인을 의미하지
않는다.
