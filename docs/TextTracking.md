# 텍스트 자간

`TextRun.letter_spacing`과 `LabelOptions.letter_spacing`은 글자 사이의 자간을
논리 픽셀로 지정한다. 기본값은 0이며 기존 글꼴의 기본 자간을 유지한다.
유효 범위는 유한한 -256부터 256까지이다. 자간은 텍스트 너비 측정,
줄바꿈, 말줄임 및 래스터화에 같은 값으로 적용한다.

플랫폼은 Core Text, DirectWrite, Pango, Android Paint 또는 브라우저
Canvas의 자간 기능을 사용한다. 브라우저 Canvas가 자간 속성을 제공하지 않는
경우 0이 아닌 요청을 조용히 무시하지 않고 실패로 보고한다. DirectWrite 1 또는
Android API 21 미만에서 해당 요청을 지원하지 못하는 경우에도 실패로 보고한다.

관련 단위 검사는 자간에 따른 너비 변화와 유효성, 웹 측정과 그리기에 전달되는
값을 확인한다. 이 검사는 실제 브라우저 렌더링이나 모든 언어의 시각적 동등성을
입증하지 않는다.
