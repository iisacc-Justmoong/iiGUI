# 반환 함수의 네이티브 수신자·인자 수명

`tests/native_factory_captures.cpp`는 LVUI 생성 코드를 창 없는 WidgetState에 연결한다.
임시 수신자와 임시 인자가 첫 실행 전에 파괴되는 두 실패를 함수 호출 없이 수명 카운터로
재현한 뒤, 함수 버전의 소유권 보존을 검사한다.

선택된 공유 객체의 참조·값 반환 함수, 이동 불가 함수 객체, 실행 중 교체와 재진입,
실패 후 이전 버전 보존·복구, Static·가변 초기 선택, 입력 내용·포커스·위젯 ID 유지와
파일 리비전 비변경을 확인한다. 문자열 이벤트·인덱스·조건부 재활성화·자기 제거도 포함한다.
혼합 인자 검사는 참조 인자를 보존하면서 같은 호출의 이동 불가 값 매개변수는 C++의
보장된 복사 생략을 유지해야 한다. 모든 인자를 좌측값 또는 우측값 참조로 강제하지 않는다.

설치·재배치 소비자는 설치한 LVUI 생성기로 임시 부모에서 반환한 함수와 임시 인자의
포획 팩토리를 생성하여 컴파일·링크한다. 실제 실행은 위의 창 없는 위젯 검사와 구분한다.
실제 LVRS 앱·OS 창·GPU·다른 플랫폼 실행은 전체 완료 감사의 별도 조건이다.

언어·공개 C++ 계약은 [LVUI 포획 수명](../../LVUI/docs/FactoryCaptures.md), 최종 범위는
[전체 완료 감사](../../LVUI/docs/Completion.md)를 따른다.

2026-10-26 macOS arm64에서 기존 창 없는 동작과 생성 코드 검사 209개를 일반·ASan·UBSan
빌드에서 각각 통과했다. 새 포획 동작은 각 12개이며 전체 수와 합산하지 않는다. 임시
수신자·인자의 실패는 함수 호출 없이 먼저 재현했다. 설치·재배치 소비자의 포획 팩토리는
컴파일·링크했으며 실행 증거와 구분한다. 원시 증거는 LVUI의
`build/lvui-completion/factory-captures-verification-20261026.json`에 기록한다.
