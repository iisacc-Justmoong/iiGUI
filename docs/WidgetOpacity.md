# 위젯 트리의 네이티브 투명도

`Widget::set_opacity(double)`는 모든 네이티브 위젯에 공통으로 적용하는 표시 속성이다.
기본값은 1이며 유한한 0부터 1까지의 값을 받는다. 잘못된 값은 `invalid_argument`로
거절하고 이전 값을 유지한다. 소유 스레드와 세대 종료 검사는 기존 Widget 계약을 따른다.

`WidgetSnapshot::opacity`는 해당 위젯에 직접 지정한 값이고 `effective_opacity`는 일반
부모와 소유 콘텐츠의 부모를 따라 곱한 값이다. 개별 색상·이미지의 alpha는 바꾸지 않는다.
작성한 투명도와 팝업 전환 애니메이션은 별도의 값이며, 실제 표시에서는 두 값을 곱한다.
스냅샷의 effective 값에는 일시적인 전환 진행률을 포함하지 않는다.

일반 자식, content host, 가상화된 자식 세대, 사용자 paint provider, 텍스트·이미지·패널·
그림자·재질, 스크롤 표시자와 팝업의 게시 레이어에 같은 투명도 곱을 전달한다.
클립이나 투명도가 다른 형제는 레이어 배치를 분리하고, 이후 형제와 부모의 표시자를
그릴 때 원래 값을 복원한다. 팝업은 클립·좌표 변환에서 분리되어도 소유 트리의 투명도를
상속한다. 단순 팝업 앵커 연결은 부모 관계를 만들지 않는다.

0은 그리기만 생략한다. 레이아웃·보임·enabled·포커스·입력·접근성 노출은 바꾸지 않는다.
입력도 막으려면 enabled 또는 visible을 명시적으로 변경해야 한다. 투명도 갱신은 콘텐츠를
다시 생성하거나 모델·파일 상태·실행 명령을 변경하지 않으며 측정을 무효화하지 않는다.
동일한 값을 다시 지정하면 표시 무효화도 생략한다. 별도 오프스크린 그룹 합성 효과는
이 계약에 포함하지 않는다.

내부 `WidgetState::drawing_snapshot(Size)`는 OS 창을 만들지 않고 현재 C++ 그리기 결과를
검사하는 접점이다. 소유 스레드에서 `(0, 8192]`의 유한한 크기를 요구한다. 실제 프레임과
동일한 배치·paint provider를 사용하며 잘못된 그리기 결과를 오류로 반환한다. GPU 픽셀이나
운영체제별 표현의 일치를 보증하는 접점은 아니다.
창 없는 중첩 콘텐츠의 팝업도 최상위 논리 viewport를 사용하므로 작은 소유 슬롯의 높이에
맞춰 메뉴 항목이 잘리지 않는다. 실제 표면이 있으면 기존 표면 크기를 그대로 사용한다.

회귀 검사는 `tests/widget_opacity.cpp`의 값·상속·소유 콘텐츠·형제 배치·사용자 그리기·
입력 유지·팝업·유효성·퇴역 9개와 LVUI의 생성 C++를 연결하는 8개 사례로 구성한다.
실행 결과와 정적 컴파일 증거는 해당 작업의 검증 기록으로 구분한다.
