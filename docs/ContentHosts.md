# 독립 콘텐츠 호스트

`WidgetBuilder::content_host(parent, id, size)`는 하나의 창과 자체 렌더링 표면 안에서
독립된 위젯 세대를 담는 일반 콘텐츠 슬롯이다. 팝업이나 별도 OS 컨트롤을 생성하지
않는다. 페이지 라우터와 문서 본문처럼 교체 가능한 콘텐츠에 사용한다.

```cpp
auto slot = widgets.content_host(parent, "page", {640, 400});
if (!slot) return std::unexpected(slot.error());
return slot->set_content([](ii::gui::WidgetBuilder& page) -> ii::core::Result<void> {
    auto root = page.vstack({}, "root");
    if (!root) return std::unexpected(root.error());
    auto title = page.label(*root, "title", {.text = "Native page"});
    if (!title) return std::unexpected(title.error());
    return {};
});
```

팩토리는 새 빌더에서 루트 뷰 하나를 구성한다. `set_content(factory, commit)`는
구성·검증, 선택적인 커밋 훅, 새 세대 공개, 이전 세대 종료 순으로 처리한다.
팩토리나 커밋 훅이 실패하면 이전 세대를 유지한다. 훅은 앱의 비공개 탐색 이력처럼
구성이 성공한 뒤 갱신할 상태에 사용한다. 임의의 사용자 코드가 일으킨 외부 부수
효과까지 되돌리는 트랜잭션은 아니다. 이전 소유 객체를 정리하는 중 호스트가
종료되면 이미 공개된 세대와 커밋은 종료되며 `closed`를 반환한다.

`content_item()`은 현재 루트, `content_item(local_id)`는 해당 세대의 위젯을
반환한다. 루트 마운트에서는 세대가 포함된 전체 ID로 조회한다. 스냅샷의
`has_content`, `content_generation`으로 교체를 관찰할 수 있다. 교체·
`clear_content()`·상위 언마운트 이후 이전 핸들은 `closed`이다. 팩토리에서
`retain`한 바인딩과 백엔드의 수명도 해당 세대에 속한다.

`WidgetBuilder::on_publish()`는 새 세대와 이를 포함하는 모든 후보가 실제로 공개된
뒤 소유 스레드에서 한 번 실행할 짧은 콜백을 등록한다. 등록은 구성 중에만 가능하며
빈 콜백과 세대당 4,096개 초과 등록은 거부한다. 팩토리나 커밋이 실패한 후보의 콜백은
실행하지 않는다. 중첩 후보와 키별 행도 최상위 교체가 성공할 때까지 기다리고, 유지된
행의 콜백은 다시 실행하지 않는다. 루트 마운트는 호스트의 교체가 확정된 뒤 전달한다.
부모 세대의 콜백을 자식보다 먼저 실행하며, 실행 중 종료된 세대의 나머지 콜백은
버린다. 콜백은 예외를 던지지 않아야 하며 예외가 발생해도 이미 완료된 공개를
되돌리지 않는다. 공유 상태를 연결하기 전의 후보를 실제 뷰와 구별하는 범용 접점이다.

`iiGUI.widget_publication`은 창이나 렌더러 없이 루트·중첩 공개 시점과 실패한 후보,
키별 행 유지·교체 및 전달 중 종료를 검사한다. 실제 OS 표시 검증과는 구분한다.

페이지 루트는 슬롯의 뷰포트를 채우며 크기 변경을 따른다. 일반 콘텐츠는 부모의
클립과 활성화 상태를 상속한다. 페이지 내부 팝업은 창 좌표의 포털로 그려지므로
페이지 경계에 갇히지 않는다. 키보드·포인터·포인터 캡처·중첩 모달 입력은 같은
호스트의 전달 경로를 사용한다. 일반 페이지의 부모 ID와 실제 팝업 ID를 구분한다.

전체 마운트는 중첩 콘텐츠와 팝업을 합쳐 4096개 노드, 콘텐츠 깊이 8을 제한으로
삼는다. 교체 중에만 이전 세대의 노드 수만큼 임시 예산을 허용한다. 새 세대 안의
중첩 슬롯 초기 구성은 가능하지만, 구성 중 다른 활성 세대를 교체하는 재진입은
`busy`이다. 모든 변경은 호스트 소유 스레드에서 수행한다.

`Widget::placement()`는 약한 세대 정체성·부모 키·형제 순서를 반환한다.
LVRS Navigator처럼 같은 부모의 순서를 보존하는 상위 모듈에서 사용한다.
내부 구현 포인터나 OS 객체를 노출하거나 트리를 소유하지 않는다. 서로 다른
세대의 동일한 문자열 ID를 같은 부모로 합치지 않는다. 조회도 소유 스레드에서
수행하며 종료된 핸들은 closed이다.

현재 슬롯의 크기는 명시적인 `Size`와 기존 스택의 flex 계약을 사용한다. 비활성
페이지 캐시, 라우팅 모션과 제스처, 전체 이벤트 버블링은 상위 구성 요소의 별도
계약이다. 콘텐츠 전용 배경 블러의 캡처 시점과 모든 플랫폼의 최종 시각 동등성도
별도 검증 대상이다.

`tests/content_host.cpp`에는 수명·실패 원자성·입력과 비활성 스타일·중첩·캡처·
팝업·예산·크기 변경·소유자 종료 사례를 등록한다. 사용자 지시에 따라 현재 단계는
컴파일·링크까지 확인하며 실행 파일 검증은 전체 작업의 마지막 일괄 단계에 수행한다.
