# 팝업 모션과 효과 캐시의 수명

전환이 있는 팝업은 배경 dim, 고유 크기의 그림자·glass, 변환되는 카드 표면과
콘텐츠를 각각의 레이어로 구성한다. 효과에는 opacity만 전달하고 카드의 배율을
그림자 마스크 크기나 Gaussian blur 입력 크기에 반영하지 않는다.

전환 시작의 dim alpha가 0이어도 해당 레이어의 투명 패널을 유지한다. 첫 표시
프레임에서 dim 레이어가 새로 삽입되며 뒤쪽 레이어의 캐시 슬롯이 바뀌는 일을 막는다.
투명 패널의 GPU 합성 결과는 0이며, 닫혀 더 이상 표시되지 않는 팝업은 제거한다.

LVRS 모션 검사는 기존 그림자 blur·배경 blur·전경 래스터화 횟수의 동일 조건을
그대로 확인한다. 추가로 같은 모션에서 마스크 생성과 배경 원본 캡처도 재실행하지
않는지 확인한다. 이동·크기·실제 배경 변경의 별도 무효화와 GPU 메모리 한도는 유지한다.
