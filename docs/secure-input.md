# 비밀 입력 필드

`InputOptions::password`는 라이선스 키 같은 실제 비밀 입력에 사용한다.
네이티브 글리프 생성 시 입력을 마스킹하고 OS 접근성 값과 복사·잘라내기에서
원문을 내보내지 않는다. 프로그램의 입력 콜백과 소유 위젯의 명시적 snapshot은
검증을 위해 원문을 유지하므로 호출자가 키의 수명을 짧게 관리해야 한다.

붙여넣기와 IME 입력은 일반 입력 계약을 사용한다. LVUI는 `password`와 `multiline`
속성을 C++ 옵션으로 생성한다. `editor_input` 테스트는 비밀 필드 의미와 잘라내기
차단을 검사하고 일반 한글 조합·UTF-16 선택 테스트도 함께 수행한다.
