# 네이티브 텍스트의 픽셀 생성

`render_text(TextRun, scale)`은 창이나 웹뷰를 만들지 않고 네이티브 글꼴 엔진으로
한글, 대체 글꼴, 줄바꿈과 정렬을 처리한다. 결과는 위쪽이 원점인 straight-alpha
RGBA8 sRGB 픽셀이다. 화면 캡처의 premultiplied-alpha 버퍼와 구분한다.

앱의 네이티브 글꼴 환경이 살아 있는 UI 소유 스레드에서 호출한다. 텍스트는 64 KiB,
생성 표면은 각 축 8192 픽셀로 제한하며, 비정상 좌표·색·크기·UTF-8은 오류이다.
Congregation은 이 결과를 문서의 래스터 자산으로 반영하며 포인터 기록이나 플랫폼
글꼴 객체를 문서에 저장하지 않는다. 테스트는 한글·이모지, 투명도, 배율과 오류를 검사한다.
