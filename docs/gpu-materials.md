# 네이티브 GPU 재질과 폴백

Metal 외에 Vulkan과 Direct3D 경로에서도 배경 흐림, 둥근 재질의 틴트·테두리,
박스 그림자와 콘텐츠 변환을 처리한다. 배경은 GPU 장면을 GPU 이미지로 복사하여
샘플링하며 CPU 화면 읽기나 브라우저 합성을 사용하지 않는다. 흐림과 그림자는
반경에 맞춘 제한된 Gaussian 커널을 사용한다.

`BackdropSource::content`는 기본 콘텐츠를, `previous_layers`는 앞서 합성한 레이어를
사용한다. 변환은 패널 기하와 클립에 적용하고 텍스트·이미지의 네이티브 래스터 결과도
같은 배율·이동·투명도에 맞춘다. Metal의 GPU 변환 캐시는 기존 정책을 유지한다.

Vulkan 테스트는 실제 GPU 캡처로 흐림, 테두리, 그림자, 패널·이미지 변환, 이전 레이어
선택과 동일 프레임의 픽셀 재현을 검사한다. Windows Direct3D 소스의 실제 실행 검증은
이번 작업 범위에 포함하지 않는다.
