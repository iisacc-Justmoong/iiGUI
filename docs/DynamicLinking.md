# 동적 라이브러리 빌드

iiGUI는 기본적으로 공유 라이브러리로 빌드한다. `BUILD_SHARED_LIBS=OFF`는 명시적 정적 빌드 선택이다. iOS에서는 프레임워크, WebAssembly에서는 사이드 모듈을 구성한다. Android Activity 진입점은 앱의 네이티브 라이브러리에 포함되는 별도 진입 코드다.

공유 대상의 유형과 주요 계약을 테스트한다. 플랫폼별 실제 동작은 해당 운영체제와 도구 체인에서 별도 검증해야 한다.

내부 SVG 코덱은 위치 독립 코드로 빌드해 iiGUI에 포함하며 별도 SDK 모듈로
배포하지 않는다.
