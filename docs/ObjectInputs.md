# 생성 C++ 객체 입력의 위젯 연결

LVUI의 [타입 지정 C++ 구성 입력](../../LVUI/docs/ObjectInputs.md)을 기존 iiGUI 위젯
트리에 연결한다. iiGUI에 런타임 타입 등록이나 스크립트 실행기를 추가하지 않는다.
구조체 값·공유 객체·raw 포인터·표준 참조의 실제 타입과 const는 생성 C++에서 결정한다.
입력의 재평가는 위젯의 표시 속성을 바꾸며 문서 파일 상태와 편집 중인 입력을 재생성하지 않는다.

`tests/native_object_inputs.cpp`는 창 없는 `WidgetState`에서 다음을 검사한다.

- 하나의 계산 결과를 여러 표시 요소와 기본값·전달 View가 공유한다.
- 비비교 구조체의 변경과 객체 멤버의 Observable publication을 표시한다.
- 선택 객체가 바뀌면 이전 구독을 끊고 새 객체를 표시하며, 불필요한 공유 소유권을 해제한다.
- 널 입력은 마지막 정상값을 보존하고 다음 정상값으로 복구한다. 최초 널 입력으로 만든
  후보가 실패하면 기존 활성화와 위젯을 보존한다.
- 입력 변경 시 로컬 편집 문자열·포커스·노드 수와 파일 revision을 보존한다.
- 루트 Window 입력·중첩 구성·조건부 활성화·키가 있는 행 재정렬에 연결한다.

`tests/layout_consumer/ObjectInput.lvui`는 임시 설치를 재배치한 뒤 공개 패키지만으로
팩터리를 생성·컴파일·링크한다. 소비자는 OS 창을 열지 않는다. 창 없는 검증은 실제
GPU 표시나 각 플랫폼의 입력·IME·접근성 실행 검증을 대신하지 않는다.
