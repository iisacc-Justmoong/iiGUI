# 편집기 화면 좌표와 타임라인 범위

편집 캔버스와 타임라인은 문서·클립을 소유하지 않는다. 앱의 문서 뷰모델은
표시할 데이터만 질의에 응답하고 편집 명령을 처리한다. `EditorCanvasViewport`는
논리 화면 좌표와 문서 좌표의 왕복, 회전·수평 및 수직 반전, 팬과 포인터 기준 확대를 제공한다.
`EditorTimelineViewport`는 프레임·스크롤·확대 배율을 바탕으로 표시할 프레임
구간과 포인터에 대응하는 프레임을 계산한다. 프레임 수와 화면 폭이 커도 표시되지
않은 프레임을 순회하지 않는다. 좌표와 배율이 유효하지 않은 갱신은 거절하며
기존 상태를 보존한다.

이들은 값 객체이며 타이머, 프레임 요청, 파일, 이미지, 앱 문서 또는 다른 SDK
모듈을 소유하지 않는다. UI는 상태 변경이나 원천의 변경 알림에서만 해당 범위를
질의한다. 편집·렌더링·음성·재생 정책은 앱과 조합된 뷰가 소유한다.
