# 텍스트 줄바꿈 대체 상태 알림

iiGUI의 네이티브 입력 필드는 요청된 자동 줄바꿈을 텍스트 배치 예산 안에서
수행할 수 없는 경우 줄바꿈 없는 배치로 전환한다. 텍스트와 선택은 그대로 유지한다.
호스트 정책이 `wrapping_fallback_changed` 콜백을 제공하면 필드 생성 시 현재 상태를
한 번 알리고, 이후 텍스트·크기·설정 변경으로 상태가 바뀔 때만 다시 알린다.
자동 줄바꿈을 요청하지 않은 필드는 `false`를 보고한다.

알림은 해당 위젯의 소유 스레드에서 배치가 반영된 후 실행한다. 콜백이 위젯을
퇴역시키거나 설정을 다시 변경할 수 있으며, 퇴역 뒤에는 더 이상 호출하지 않는다.
콜백이 없는 정책은 그대로 사용할 수 있다. 이 알림은 배치 성공을 보증하거나
텍스트 크기 제한을 늘리지 않는다.
