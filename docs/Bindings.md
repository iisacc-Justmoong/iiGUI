# 컴파일된 속성 바인딩

`BindingScope`는 `ii::core::Observable<T>`의 값과 변경을 C++ 위젯에 연결한다.
문자, 활성 상태, 체크 상태, 수치, 현재 인덱스 갱신을 직접 호출한다. 임의 속성 이름을
찾는 레지스트리나 런타임 표현식 해석을 사용하지 않는다.

위젯 팩토리는 `BindingScope`를 `WidgetBuilder::retain()`으로 소유한다. 팝업의 열림 단위
콘텐츠도 각각의 바인딩 스코프를 가진다. 해제한 콘텐츠의 구독은 종료되며 부모 C++
백엔드를 다시 생성하지 않는다. 모든 값 접근과 전달은 Core 속성의 소유 스레드에서 수행한다.

초기 값 적용이 실패하면 마운트를 거절한다. 이후 잘못된 값에 대한 위젯 오류는 관측자 예외로
전달한다. 이미 닫힌 위젯 세대는 갱신하지 않는다. 초기 값과 이후 통지가 같은 setter를 사용하므로
활성/선택/입력 정책을 우회하지 않는다.
