# 웹 텍스트 입력과 조합

웹 호스트는 포커스된 iiGUI 편집 위젯을 브라우저 텍스트 서비스와 연결한다.
표시·배치·선택과 실제 편집 상태는 iiGUI가 소유하고 GPU 캔버스에 그린다.
브라우저 입력 요소는 키보드·IME·클립보드를 연결하는 투명한 입력 통로다.

문자 삽입·삭제·붙여넣기와 선택 범위는 UTF-16 범위로 변환하고 기존 텍스트 서비스에
전달한다. IME 조합은 후보 변경·확정·취소를 구분한다. 창 또는 편집기가 바뀌면 이전
세대의 비동기 입력은 폐기한다. 편집 데이터나 선택이 외부에서 바뀌어 브라우저의 기준
값과 다르면 입력을 적용하지 않고 현재 상태를 다시 게시한다.

읽기 전용은 편집하지 않으며 비밀번호 입력은 브라우저의 password 입력 통로를 사용한다.
비밀번호와 일반 입력은 포커스를 잃거나 위젯이 제거될 때 통로에서 비운다. 문서 전체를
복사할 수 없는 사용자 정의 공급자에는 부분 문서 편집을 잘못 적용하지 않는다. 현재
웹 통로는 UTF-8 64 KiB 이하의 전체 텍스트와 안정적인 텍스트 리비전이 있는 편집기를
대상으로 한다. 이 한계는 가상 대용량 편집기를 지원한다는 뜻이 아니다.

포커스·입력·선택·크기 변경 이벤트가 있을 때만 상태를 동기화한다. 유휴 상태의 폴링이나
별도 프레임 타이머를 만들지 않는다. 표준 브라우저의 입력 이벤트 순서는
[W3C Input Events Level 2](https://w3c.github.io/input-events/)를 따른다.
