# 소스 구조

공개 헤더와 구현은 `src/` 아래 책임에 따라 함께 둔다. 앱 수명과 전달은 `Core/`, 플랫폼 호스트와 데스크톱 연결은 `Platform/`, 렌더링은 `Graphics/`, 폰트와 텍스트는 `Text/`, 위젯은 `Widgets/`, 모양과 프레젠테이션은 `Presentation/`, 통합 공개 헤더는 `API/`에 둔다.

빌드 중 생성한 연결 헤더와 설치된 원본 헤더는 기존 `<iiGUI/...>` 경로를 유지한다. `iiGUI.source_layout`, 공개 경계 및 설치 소비자 검사는 소스 분류와 API 경계를 함께 확인한다. 이 구조 변경 자체는 다른 운영체제나 실제 창·GPU 실행의 검증을 뜻하지 않는다.
