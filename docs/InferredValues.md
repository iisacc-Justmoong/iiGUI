# LVUI 타입 생략 선언의 위젯 연결

일반 `let`·`var`·`@Static let`은 LVUI가 생성한 C++의 실제 타입으로 값 또는 함수
저장소를 선택한다. iiGUI에는 별도의 타입 해석기나 함수 실행기를 추가하지 않는다.
기존 위젯 이벤트와 속성 갱신이 LVUI Native·iiSDKCore 그래프를 사용한다.

`tests/native_inferred_values.cpp`는 두 실제 `.lvui`를 생성·컴파일한 뒤 창 없는
`WidgetState`에 연결한다. 메서드 참조, 이동 전용 반환 함수, 함수 필드, 별칭의
갱신, Static 선택, 가변 교체, 임시 수신자·인자 수명과 타입 지정 구성 입력의 전달을
검사한다. 함수 선택 시 작업을 실행하지 않으며 입력값·포커스·위젯 ID를 보존한다.
순수 뷰 선택으로 파일 revision이 바뀌지 않는 계약도 검사한다.

실패한 함수 선택은 마지막 정상값을 유지하며 원천이 복구되면 갱신을 재개한다.
재진입 호출과 자기 제거 중에는 입장한 버전을 유지하고 종료 후 구독과 포획을 해제한다.
이 검사는 실제 OS 창·플랫폼 입력·GPU 그리기의 검증과 구분한다.
