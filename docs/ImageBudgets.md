# 명시적인 이미지 래스터 예산

기존 `rgba_image`와 `svg_image`의 기본 한도는 8192 픽셀 변 길이와 16 Mi 픽셀이다.
큰 문서 미리보기처럼 호출자가 메모리 수명을 관리하는 경우 `ImageBudget`을 받는
오버로드로 최대 64 Mi 픽셀까지 명시적으로 요청할 수 있다. 기본 경로의 한도를
전역으로 확대하지 않는다. 변 길이 8192, 입력 SVG 1 MiB 및 정확한 RGBA8 버퍼 길이
검사는 같은 경로에서 유지한다. 텍스트 래스터 캐시의 기존 예산도 그대로 유지한다.

예산 0과 64 Mi 픽셀을 넘는 요청은 잘못된 입력이다. 래스터 생성 후의 캐시·텍스처·
PNG 인코딩·전달 버퍼 수명과 메모리 예산은 호출자가 별도로 관리한다. 래스터 허용은
모든 GPU에서 해당 크기의 업로드가 성공한다는 의미가 아니다.

`tests/image_budget.cpp`는 명시적 예산 전달, 기존 오버로드, 8192×1 래스터와 잘못된
한도를 창 없이 검사한다. 8192×8192의 실제 메모리·GPU 검증으로 확대 해석하지 않는다.
