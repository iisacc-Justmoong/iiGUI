# 위젯 내부 영역의 스크롤 노출

여러 줄 편집기의 커서처럼 위젯보다 작은 특정 영역은 `Widget::reveal_local_rect`로
스크롤 조상에게 알린다. 좌표는 호출 위젯의 로컬 논리 좌표이다. 가장 안쪽부터
일반 스크롤 뷰를 이동하고 각 이동 후 현재 위치를 다시 계산하며 범위를 클램프한다.
이미 보이는 영역은 이동하지 않는다. 가상 콘텐츠의 오프셋은 공급자가 소유하므로
이 API가 직접 변경하지 않는다. 잘못된 값과 퇴역한 핸들은 거절한다.

이 호출은 명시적인 이벤트에 반응하며 주기적으로 실행되지 않는다. 서로 다른 위젯
트리나 팝업 사이의 좌표 전달은 현재 계약에 포함하지 않는다.
